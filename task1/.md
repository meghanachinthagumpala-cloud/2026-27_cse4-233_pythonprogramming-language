1. Problem Statement
To develop a Python program that selects eligible students for university scholarships based on aggregate marks, subject-wise minimum marks, attendance percentage, and family income.

The system ranks eligible students and resolves ties using predefined rules.
2. Algorithm
1. Start the program.
2. Read the number of students.
3. Enter each student's name, aggregate marks, subject marks, attendance, and family income.
4. Check the eligibility criteria:
   - Aggregate marks ≥ 75%.
   - Each subject mark ≥ 60%.
   - Attendance ≥ 75%.
   - Family income ≤ ₹2,50,000.
5. Store eligible students.
6. Rank students based on aggregate marks.
7. If marks are equal, give priority to higher attendance.
8. If attendance is also equal, give priority to lower family income.
9. Display the final scholarship ranking.
10. Stop.
