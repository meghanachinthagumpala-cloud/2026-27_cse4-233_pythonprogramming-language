1. Problem Statement
To develop a Python program that evaluates students for university scholarships based on aggregate marks, subject-wise minimum marks, attendance percentage, and family income. The system identifies eligible students, ranks them according to their performance, and resolves ties using predefined rules.
2. Algorithm
1. Start the program.
2. Read the number of students.
3. Enter each student's name, aggregate marks, subject marks, attendance, and annual family income.
4. Check the eligibility criteria:
   - Aggregate marks ≥ 75%.
   - Minimum subject marks ≥ 50.
   - Attendance ≥ 75%.
   - Annual family income ≤ ₹2,50,000.
5. If all conditions are satisfied, declare the student eligible.
6. Store all eligible students.
7. Sort eligible students based on:
   - Higher aggregate marks.
   - Higher attendance.
   - Lower family income.
8. Display the ranked eligible students.
9. Stop.
